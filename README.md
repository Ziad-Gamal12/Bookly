# 📚 Bookly App

Bookly is a Flutter app that lets you browse, search, and preview books using the **Google Books API**. It’s built with **Clean Architecture**, **Bloc/Cubit**, and delivers a smooth reading experience with elegant UI animations.

---

## 🚀 Key Features
- Animated splash screen for a smooth app start  
- Browse best-selling and trending books easily  
- View detailed book info: title, author, description & rating  
- Smart search to quickly find any book you need  
- Integrated with Google Books API for accurate results  
- Modern, clean, and responsive Flutter design  
- Smooth animations for better reading experience  
- Fast performance with Bloc state management  
- Open book previews and external links instantly  
- Your personal library to explore books anytime, anywhere  

---

## 🛠️ Tech Stack  
- **Flutter & Dart**  
- **Google Books API**  
- **Bloc / Cubit (State Management)**  
- **GoRouter**  
- **URL Launcher**  
- **Clean Architecture**  
- **Custom Animations**
